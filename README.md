# ZZZKeyEcho

《绝区零》输入显示工具：把键盘 / 鼠标 / 手柄输入实时画在屏幕上；并支持用 OBS「浏览器源」单独叠加（真透明背景，主播屏幕和观众画面一致）。

## 技术栈

- **.NET 8 / C# / WPF**（`net8.0-windows`），自包含单文件发布（win-x64，使用者免装 .NET）
- **输入**：Win32 低级钩子（键鼠）、XInput、HID 直读（DualSense / DualShock 4）
- **界面**：WPF（悬浮窗 / 设置窗 / 调试面板 / 托盘）；网页输出由内置 `HttpListener` 提供透明 HTML 页面
- **测试**：xUnit，共 116 个用例；配置为程序同目录的 `config.json`

## 目录

```
src/ZZZKeyEcho.Core    引擎与输入（配置、映射、记录引擎、手柄、Win32）
src/ZZZKeyEcho.App     界面（悬浮窗 / 设置 / 调试面板 / 浏览器源输出 / 托盘）
tests/                 单元测试
tools/pack.ps1         打包脚本
assets/                内置图标、网页模板、默认配置
```

## 常用指令

```powershell
dotnet run --project src/ZZZKeyEcho.App          # 运行（开发）

dotnet build                                     # 构建
powershell -File tools/pack.ps1 -Version 0.1.2   # 打包便携版 → publish/*.zip + .sha256
```

## 快速开始

1. 下载 Release 里的 `ZZZKeyEcho-v0.1.2-win-x64.zip`，解压到任意目录
2. 双击 `ZZZKeyEcho.exe`，悬浮窗出现在屏幕左上角
3. 默认热键：`F2` 开始/结束录制 ｜ `F5` 清除悬浮窗记录 ｜ `F8` 显示/隐藏 ｜ `F9` 锁定/解锁 ｜ `F10` 打开/关闭设置 ｜ `F11` 调试模式

> 若游戏以管理员身份运行，请同样以管理员身份运行本程序，否则系统会拦截输入监听。

> 首次运行会弹出 UAC 提示，请点「是」：程序以管理员权限运行，否则当游戏也以管理员启动时会收不到输入。

## 0.1.2 更新（简要）

- 默认以管理员权限运行；开机自启改用任务计划程序；新增单实例检测。
- 新增「操作录制」：F2 开始/结束，CSV 存 `ActivityLogs`；支持悬浮录制按钮、打开目录、导出 HTML、删除文件。
- 新增全局热键 F5 清除悬浮窗记录；F10 改为打开/关闭设置；托盘菜单同步。
- 悬浮窗新增「文字字号」，网页端字号与其同步（移除单独的网页字号设置）。
- HTML 导出重做：时间轴 + 表格双页面，支持筛选、播放/暂停/重播、0.1–3.0x 速度、深浅主题、轴显隐与排序、表格行跳转。
- 新增更新检测（启动静默检测 + 手动检测，明确区分「已是最新」与「网络失败」）。
- 兼容旧 config.json：缺失字段自动补默认值；旧 F12 录制热键迁移为 F2。

## 在 OBS 里叠加

设置 → **OBS 输出** → 勾选「开启网页输出」→ 复制地址 → OBS 添加「**浏览器**」源并粘贴该地址（背景透明，不影响游戏源；主播端仍使用原生悬浮窗）。
