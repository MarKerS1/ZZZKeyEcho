# ZZZKeyEcho

《绝区零》输入显示工具：把键盘 / 鼠标 / 手柄输入实时画在屏幕上；并支持用 OBS「浏览器源」单独叠加（真透明背景，主播屏幕和观众画面一致）。

## 技术栈

- **.NET 8 / C# / WPF**（`net8.0-windows`），自包含单文件发布（win-x64，使用者免装 .NET）
- **输入**：键盘 Raw Input + 鼠标低级钩子、XInput、HID 直读（DualSense / DualShock 4）
- **界面**：WPF（悬浮窗 / 设置窗 / 调试面板 / 托盘）；网页输出由内置 `HttpListener` 提供透明 HTML 页面
- **测试**：xUnit，共 128 个用例；配置为程序同目录的 `config.json`

## 目录

```
src/ZZZKeyEcho.Core    引擎与输入（配置、映射、记录引擎、手柄、Win32）
src/ZZZKeyEcho.App     界面（悬浮窗 / 印章 / 设置 / 调试面板 / 浏览器源输出 / 托盘）
tests/                 单元测试
tools/pack.ps1         打包脚本
assets/                内置图标、网页模板、默认配置
```

## 快速开始

1. 下载 Release 里的 `ZZZKeyEcho-v0.1.3-win-x64.zip`，解压到任意目录
2. 双击 `ZZZKeyEcho.exe`，悬浮窗出现在屏幕左上角
3. 默认热键：`F2` 开始/结束录制 ｜ `F5` 清除悬浮窗记录 ｜ `F7` 显示/隐藏印章输出 ｜ `F8` 显示/隐藏按键悬浮窗 ｜ `F9` 锁定/解锁 ｜ `F10` 打开/关闭设置 ｜ `F11` 调试模式

> 若游戏以管理员身份运行，请同样以管理员身份运行本程序，否则系统会拦截输入监听。

> 首次运行会弹出 UAC 提示，请点「是」：程序以管理员权限运行，否则当游戏也以管理员启动时会收不到输入。

## 0.1.3 更新（简要）

- **新增「印章」**：把屏幕上一个区域实时复制到独立输出窗，不改游戏内 UI；支持最多 8 组源→输出。
- **编辑模式**：框选源区域、拖动源/映框、删除、保存布局；按键悬浮窗与录制按钮也会以代理框显示，可一起调整。
- **输出外观**：每组独立设置比例（以中心缩放）、边框粗细/不透明度/颜色、圆角、内边距、画面不透明度；映射画面严格等于「源尺寸 × 比例」，边框绘制在画面外侧。
- **OBS 单画布**：新增 `/stamps` 页面，OBS 只加一个浏览器源即可输出所有印章；画布尺寸跟随游戏窗口/屏幕分辨率，支持 15/30/60 FPS。
- **印章默认布局**：印章设置页提供「导入印章默认设置」，内置左下角（2 枚）与右侧（3 枚）两套实测布局，按分辨率自动换算。
- **显示/隐藏印章输出**：新增默认热键 `F7`、托盘菜单项与设置页开关；仅隐藏本地输出，OBS 继续输出。
- **跟随游戏自动显示/隐藏**：按键悬浮窗与印章可分别设置，本地与浏览器源同步跟随游戏状态（印章默认关闭）。
- **热键提示**：所有全局热键触发后，屏幕上方居中显示 3 秒提示，连续触发会立即替换上一条。
- **热键修复**：取消勾选即时注销该热键；改键在按键释放后再注册，避免「F1–F10 全部被占用」的误报。
- **窗口与输入**：键盘采集改为 Raw Input，不再占用全局键盘钩子链，不影响其他软件（如截图工具）的 F1 等快捷键；录制按钮与顶部提示改为不可激活工具窗口，不再出现在 Alt+Tab；所有悬浮窗在应用样式后重新置顶。
- **文案与设置页**：新增「印章设置」页；「悬浮窗外观」改名「按键悬浮窗」，「OBS 输出」改名「按键显示 · OBS 输出」；托盘菜单按热键顺序重排，印章项不带勾选框。
- **配置兼容**：配置版本 3 → 4；旧配置自动补 `stamps` / `hideStamps` 默认值，导入/重置时深拷贝印章列表。
- **修复**：设置页打开即崩溃（只读属性双向绑定）、单实例误报（读不到路径的残留进程）、个别印章在 OBS 里只剩边框（网页流断线重建）。

## 在 OBS 里叠加

**按键显示**：设置 → **按键显示 · OBS 输出** → 勾选「开启网页输出」→ 复制地址 → OBS 添加「**浏览器**」源并粘贴该地址（背景透明，不影响游戏源；主播端仍使用原生悬浮窗）。

**印章**：设置 → **印章设置** → 勾选「开启网页输出」，并给需要输出的印章勾选「OBS 网页输出」→ 复制 `/stamps` 地址 → OBS 再加一个浏览器源，宽高填设置页显示的画布尺寸。所有印章共用这一个源，删除/重排不会失效。
